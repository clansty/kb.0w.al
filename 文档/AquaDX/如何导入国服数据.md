# 如何导入国服游戏数据

## 导出

你需要把你的国服成绩导出为 UserMusicDetailList 格式的 JSON 数据

### 方法一

使用 Telegram 的 [麥當勞❤️送餐机器人](https://t.me/McDLdshEartBot) 可以导出 GetUserMusic 的结果。绑定后使用 `/getplaydata json` 即可

![[Pasted image 20241003160856.png]]

> [!NOTE]
> 此 Bot 和 AquaDX 并没有关系，只是此 Bot 可以一键导出 UserMusic

### 方法二

自己通过任何可用的方法导出 GetUserMusic 的结果并以 JSON 保存下来

### 方法三

使用群友 户山兔兔 制作的[落雪 / 水鱼成绩导出工具](https://code.danieltoyama.fun/MaiData2Aqua/) 导出 JSON 文件

此工具提供简要版本和完整版本账号数据的功能，简要版本和前面的方法导出的文件是一样的，导入后将和当前 AquaDX 的游玩数据合并，并取更高分数保存。选择完整账号数据的话，导入时将会清除 AquaDX 现有的账号数据

> [!WARNING]
> 如果你使用此工具导出时选择了完整账号数据，导入 AquaDX 时你现有的游玩数据想会被清除
## 导入

登录 [AquaNet](https://aquadx.net/)，点击导入按钮后选择导出的文件即可自动导入。你可能需要先在 AquaDX 玩过 Maimai 才能正常导入 UserMusicDetailList 格式的数据（上面的方法导出）

![[Pasted image 20241003161137.png]]

目前的导入策略是，如果有重复的歌，那么 成绩、Combo、Sync、DX 分数、游玩次数 都会取最高保存

> [!NOTE]
> 导入成功之后，你的个人资料页面不会马上反应最新的成绩。你必须登录一次游戏，保存退出之后才能看到新导入的成绩
